ℹ️ About Fire Hub
Static, browser-based toolkit.
Fire Hub is designed to be hosted on GitHub Pages. The generators run in the browser and do not require a server or database.
The version library distinguishes Minecraft versions from Eaglercraft client lines. Eaglercraft is not an official one-to-one list of Minecraft releases; several Eaglercraft lines are community ports or forks.
